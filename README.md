ENG

SC2 (Scrap Clicker 2) bot for auto-completing quests by speeding up the game through Game Guardian. Tested on LDPlayer.

GG (Game Guardian) requires root, so you need to enable root access in the emulator's settings beforehand.

Setting up the speed hack in GG: select the process, tap on settings (the tab next to the SC2 app icon in the GG menu). Then tap Speed Hack: Functions and check every box that's highlighted green.

Setting up the speeds in GG: in the same tab where the speed hack settings were, scroll down and you'll find Speed Hack: Speeds. Remove all the speeds here and set 0.000000001;1;10,000;1,000,000,000, then confirm.

You can minimize the menu using the X in the top-right corner. Open the quests menu. Next, drag the GG icon to the center, onto the word Prestige, and hold it down — two arrows will appear (GG needs a couple of seconds to load the speed hack). After that, tap the right arrow once and start the script.

Advantages:

Automatically skips quests, only completing "Play for X minutes" quests, since with time acceleration they finish instantly.
Has protection against popup windows such as: leveling up from quest XP, global challenge/team challenge (since these pop up in any menu).
Double crash protection: 1. Slows down the speed every minute (sometimes helps, but this just delays the inevitable game crash). 2. If the game does crash, it can automatically restart the game and return to farming.

RUS

SC2(Scrap Clicker 2) бот для авто-выполнения квестов с помощью ускорения игры через Game Guardian. Проверено на LDPlayer.

GG(Game Guardian) требует рут, так что нужно заранее включить в настройках эмулятора рут права.

Настройка спидхака в GG: выбрать процесс, нажать на настройки(вкладка рядом с иконкой приложения SC2 в меню GG). Далее нажать на Спидхак: функции и поставить галочки везде где горит зеленым.

Настройка скоростей в GG: в той же вкладке где находилась настройка спидхака пролистать вниз и там будет Спидхак: скорости. Тут нужно убрать все скорости и установить 0,000000001;1;10 000;1 000 000 000 потом подтверждаем.

Можно сворачивать меню на крестик в правом верхнем углу. Открываем меню с квестами. Далее нужно перетащить иконку GG по центру на слово Престиж и зажать на эту самую иконку, появятся две стрелки(GG потребуется пару секунд чтобы загрузить спидхак) после этого нужно один раз нажать на правую стрелочку и запускать скрипт.

Преимущества:
1) Автоматически скипает квесты, выполняя только квесты "Играть Х минут" так как с ускорением времени они выполняются моментально.
2) Есть защита от вылезающих окон таких как: поднятие уровня за опыт с квестов, глобальный челлендж/тим челлендж(так как они выскакивают в любой менюшке)
3) Двойная защита от краша: 1. Каждую минуту замедляет скорость(иногда помогает но это просто откладывает неизбежный краш игры) 2. Если все-таки игра крашнется, может автоматически запустить игру и вернуться к фарму.
